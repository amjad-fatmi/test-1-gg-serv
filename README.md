# Ground Game Consulting Services — website

Static marketing site. All pages are generated by one Python script (standard library only).

## Build

```bash
python3 src/build.py
```

Output goes to `site/`. The build also checks that every internal link works and every page is reachable from the homepage, and fails if not.

## Edit

- Contact details, city and the contact-form endpoint: the `FIRM` dict at the top of `src/build.py`.
- Page copy, tiers, comparison table and FAQ: the content section of `src/build.py`.
- Styles and scripts: `src/assets/site.css`, `src/assets/site.js`.

## Preview locally

```bash
python3 src/build.py && python3 -m http.server 8091 --directory site
```

## Deploy (Netlify)

`netlify.toml` sets the build command (`python3 src/build.py`) and publish directory (`site`). Connect this repo in Netlify and every push to `main` redeploys.

## Contact form

Submissions go to Formspree (`FIRM["form_endpoint"]`). Manage them at formspree.io.
